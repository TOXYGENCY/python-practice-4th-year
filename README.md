# Общий калькулятор на Python

Переводит инфиксную (обычную) запись математического выражения (напр. `2+5*3*(4-2)`) в обратную польскую нотацию (напр. `2 5 3 * 4 2 - * +`), на основе которой вычисляет результат (`=32`).

Фичи:
- Графический интерфейс. Цветовое выделение кнопок.
- Ввод в поле кнопками или с клавиатуры.
- Нативная поддержка:
    - Базовые 4 операции: `+ - / *`
    - Квадратного корня `sqrt(x)`
    - Степени `a^x` (или `a**x`)
    - Натурального логарифма `ln(x)`
    - Скобок `(x)`
    - Модуля `|x|`
    - Синуса `sin(x)`
    - Косинуса `cos(x)`
    - Тангенса `tan(x)`
    - Котангенса `ctan(x)`
