# Общий калькулятор на Python

Переводит инфиксную (обычную) запись математического выражения (напр. `2+5*3*(4-2)`) в обратную польскую нотацию (напр. `2 5 3 * 4 2 - * +`), на основе которой вычисляет результат (`32`).

Фичи:
- Графический интерфейс. Цветовое выделение кнопок.
- Ввод в поле кнопками или с клавиатуры.
- Вставка функций по нажатию на кнопку.
- Автозамена буквы `x` на 1 при расчёте.
- Независимость от пробелов между операциями/операндами.
- Сохранение ввода после расчёта.
- Ошибка при отсутствии явного оператора между операндами (в скобках/модуле).
- Игнорирование лишних символов (не предусмотренных программой).
- Нативная поддержка:
    - Базовые 4 операции: `+ - / *`
    - Унарный минус `-x`
    - Квадратного корня `sqrt(x)`
    - Степени `a^x` (или `a**x`)
    - Натурального логарифма `ln(x)`
    - Скобок `(x)`
    - Модуля `|x|`
    - Синуса `sin(x)`
    - Косинуса `cos(x)`
    - Тангенса `tan(x)`
    - Котангенса `ctan(x)`

НЕ фичи:
- Числа с плавающей запятой
- Вложенные модули
- Все, что не перечислено
